## 2026-07-29 notch receipt

On a MacBookPro18,1 running macOS 15.7.7, three expand/collapse cycles each
verified eight hidden-lane items removed from the rendered menu bar. Two
standalone third-party items and two system items remained visible; expanding
restored the hidden items. See
[`HIDE-001.json`](../initiatives/v0.2-production-hardening/receipts/HIDE-001.json).

This is scoped built-in-display evidence. It does not close the external-display
matrix, repeated third-party movement, panel activation across both owner
classes, or notarized release.

## 2026-07-29 performance and upgrade receipts

The installed v0.2 app produced 61 process samples across five minutes after 12
requested reveal cycles (20 completed presentation observations). RSS peaked at
68.16 MiB, cold shell/content took 1.50/201.06 ms, and cached warm reveal p95
was 11.83 ms. Review found the original CPU input used rounded `ps %cpu`; the
gate now derives CPU from cumulative process CPU-time deltas. A replacement
five-minute CPU observation remains pending because the harness visibly cycles
the panel and now requires explicit active-user confirmation.

An in-place 0.1.0 to 0.2.0 Apple Development-signed install preserved the
configuration byte-for-byte. The uninstall command now refuses to remove the
app while Launch at login remains enabled, because the installed app must first
unregister its Service Management item.

## 2026-07-31 local closeout

The guarded `make verify-publication` gate passed with 162 Swift tests, script
tests, the 469-finding formatter ratchet, docs validation for 11 requirements
and 24 acceptance criteria, a warnings-as-errors release build, and both
gitleaks scans. `make release-artifact` produced the ignored local
`NicosHiddenMenuBar-0.2.0.zip` archive, checksum, and provenance receipt; the
receipt correctly leaves `distribution_ready=false` for the dirty,
Apple-Development-signed, unstapled tree.

The installed runtime is now unambiguous: `/Applications/NicosHiddenMenuBar.app`
owns the active process and launch service, the pre-0.2 `NicosDev` launch agent
is absent, and its plist is archived under
`~/.config/nicos-hidden-menubar/legacy-launch-agents/`. The old app bundle was
left in place as a rollback artifact. `make verify-installed` confirms the
installed and release bundles share CDHash
`d377acd3326504f8fb5b91b41c289cf7c55d3769`.

The headless smoke report and reviewed settings screenshot remain under
`.local/headless-smoke/20260731-182516/`. The visible performance refresh,
external-display and activation/movement hardware, Screen Recording completion,
Developer ID/notarization, clean-machine, public-CI, and GitHub publication
gates remain intentionally open.
