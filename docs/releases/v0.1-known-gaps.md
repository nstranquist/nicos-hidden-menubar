# v0.1 known gaps

This record preserves the difference between the frozen v0.1 contract and live
behavior observed during hardening. **v0.2 software work has closed several of
these;** see [`v0.2-progress.md`](v0.2-progress.md) for the current truth.

## P0/P1 product gaps

- ~~Panel selection does not directly activate an item when experimental movement
  is disabled; it falls back to inline expansion.~~ **Closed in v0.2 (ACT-001):**
  in-place activation with explicit outcomes; Accessibility required.
- ~~The spacer cannot reliably hide arbitrary items on a notched display.~~
  **Closed in v0.2 (HIDE-001 / ADR-0005):** the failure was a false negative
  caused by treating the Window Server menu-bar backdrop as an app item.
  Collapse now uses an exact-ID verified spacer on notched and regular displays.
  A genuine failure remains expanded with `hide_unavailable`; it does not
  automatically move third-party items or require Accessibility.
- ~~`bundleID:title` cannot distinguish repeated image-only Control Center items.~~
  **Closed in v0.2 (ITEM-001):** versioned identity + AX extras titles + symbols.
- External-monitor behavior has pure geometry coverage but no current physical
  multi-monitor acceptance evidence. **Still open (DSP-001-B).**

## Quality and distribution gaps

- `StatusSectionController` owns too many responsibilities and lacks direct
  integration tests. **Still open** (orchestration debt).
- ~~ScreenCaptureKit captures are sequential and uncached.~~ **Closed in v0.2
  (CAP-001):** shell-first panel, bounded ScreenCaptureKit cache, and app/SF
  Symbol fallbacks when capture is unavailable.
- ~~No macOS CI~~ — **CI workflow** runs `make verify-publication` on macOS-15;
  coverage/warnings-as-errors gates remain light.
- Source installation is ad-hoc signed, so privacy permissions may be requested
  again after rebuilding. **Still true.**
- Signed/notarized release, update, and clean-machine rollback are deferred
  (**REL-001**).

## What v0.1 does prove

- local-only configuration and diagnostics;
- valid Swift package tests and native settings smoke;
- event-driven display parameter observation;
- real window-server discovery and diagnostics;
- notch failure detection and compact recovery;
- adaptive below-menu-bar panel layout;
- launch-at-login integration.
